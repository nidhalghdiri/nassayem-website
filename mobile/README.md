# Nassayem — staff mobile app

Expo (React Native) app for Nassayem Salalah staff. It talks to the website's
`/api/mobile/v1/*` routes and signs in with the same accounts as the website
admin.

| | |
|---|---|
| Name / bundle ID | Nassayem · `com.nassayem` (iOS and Android) |
| Stack | Expo SDK 58, Expo Router, Uniwind (Tailwind 4), TanStack Query, Zod, i18next |
| Languages | English and Arabic (full RTL) — Inter / Tajawal like the website |

## Run it

```bash
cd mobile
npm install
cp .env.example .env        # point EXPO_PUBLIC_API_URL at your website
npx expo start              # then open the development build on your phone
```

The app uses native modules that Expo Go does not include, so you need a
**development build** installed on the phone once (rebuild only when native
dependencies change):

```bash
npx eas-cli@latest build --profile development --platform android   # or ios
```

This Mac (macOS 12) cannot run the current Xcode, so iOS builds always go
through EAS in the cloud. Android can also build locally with
`npx expo run:android` (Android SDK + Java 17 are installed).

To test against local API changes, run `npm run dev` in the website folder and
set `EXPO_PUBLIC_API_URL` to `http://<your-mac-LAN-IP>:3000` (phone on the same
Wi-Fi) or `http://10.0.2.2:3000` (Android emulator).

## Layout

```
src/app/              routes (Expo Router)
  _layout.tsx         fonts, i18n, providers, signed-in / signed-out guard
  login.tsx
  (app)/              tabs once signed in: index (home), tasks, profile
src/components/ui/    Text, Button, TextField, Card, Badge, Screen, states
src/lib/api/          fetch client (Bearer token, Zod-validated) + endpoints
src/lib/auth/         session context; token in SecureStore
src/lib/i18n/         en.ts / ar.ts; switching EN⇄AR restarts the app for RTL
```

### Shared code with the website

`@shared/*` resolves to the website's `lib/` folder (tsconfig paths + Metro
`watchFolders`), so task permissions, statuses and labels are not copied. Only
import files that have **no Prisma, Next.js or `@/` imports** — currently
`lib/tasks/*` and `lib/buildingLabel.ts`. Folders that hold Tailwind classes
must also be listed with `@source` in `src/global.css`.

## API (website side)

| Route | |
|---|---|
| `POST /api/mobile/v1/auth/login` | `{ email, password }` → `{ token, user }` |
| `GET/PATCH /api/mobile/v1/me` | profile, role, buildings, modules; PATCH saves the language |
| `GET /api/mobile/v1/config` | `{ minAppVersion }` — older builds show "Update required" |
| `POST/DELETE /api/mobile/v1/devices` | register / remove the phone's Expo push token |

The existing `/api/tasks/*` routes also accept the Bearer token, because
`getCurrentAdminUser()` reads either the cookie or the `Authorization` header.
Raising `AdminUser.sessionVersion` signs that person out on every device.
